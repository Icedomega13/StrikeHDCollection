Amiga Sound Labeler

Listen to each Amiga sound and give it a name, then pick which sound each game event should use. Save for the game downloads an amiga_sfx.ini: put it in %APPDATA%\DesertStrikeHD\DesertStrikeHD\ and restart the game. Your labels are kept in this browser. Keys: ↑ ↓ pick a sound, Space play it (when not typing).

The 26 Amiga sounds

Play a sound, then type what it is (for example "chain gun", "missile launch", "big explosion").

Which sound the game uses

Each game event plays the Amiga sound picked here. "Genesis sound" keeps the original. Green = changed from the default.

The in-game Sound Lab (Settings › Audio) shows the id of each sound the game plays, if you hear one that isn't listed here.
